# 网页讨论与本机实验决策

2026-09-23 已打开并实际发送设计审查请求到用户指定对话：
https://chatgpt.com/c/6aa9561d-3c6c-83e8-9f05-ad4c5a44fc68 （“评价研究原型”）。
正文读取通过浏览器可见 DOM 完成；网页建议作为待检验方案，不作为实验结论。

网页版指出：MCQA 的映射后 JS 就是已有的等变一致性方法；NLI 的非唯一允许集合不能使用隐藏 gold。
无标注 NLI 可以使用不依赖 gold 的矛盾概率边缘 Bernoulli-JS。均匀分布或稳定错误也可能满足一致性，
因此主指标采用 all-transform-correct（ATC），同时要求准确率非劣和关系违反率下降。
它还建议物理分离 oracle、按语义去重、增加 OOD 样本、等计算量 SFT 控制以及按 bundle bootstrap。

本机采纳这些关键审查意见：

- 基模固定本地 Qwen2.5-0.5B-Instruct，LoRA q/v，15 个配对最终模型（5 arms × 3 seeds）。
- 新版保留原始训练/开发/ID-test 全部样本，OOD 增至每任务 2048。原始小数据集留存。
- 保留已抽样的每任务 102 个标签（9.9609%），而非重抽网页建议的 96；所有臂共用相同 gold IDs。
- 训练只读精简的 train_public.json；oracle.json 只在独立评估阶段加载。
- 加入 standard consistency 臂，分离已知方法与 set-valued 项的增量；MCQA 是已知方法的正对照。
- 加入真正将计算用于重复 gold CE 的 sft_compute；报告有效 token 和序列预算，误差不超过 1%。
- 不做超参数搜索，使用预定 0.3 权重和 256 步；三种种子全部从相同基模独立训练。
- BF16 只用于训练；正式概率评估使用 FP32，避免已观察到的 BF16 批量数值差异污染关系指标。
- 本轮是两个任务共同训练一个 adapter 的小规模后训练试验；不是 DPO/GRPO，也不证明跨领域、因果推断或研究创新。
- OOD 同时改变复杂度和措辞，不能将收益单独归因于其中一种变化。

成功门槛已在 protocol.json 中冻结：每任务对等计算 SFT 及精确增强对照，ATC 差值置信区间下界 > 0，
准确率差值下界 > -1pp，违反率差值上界 < 0。若未通过，诚实记录失败或不确定，不改测试集或挑 seed。

第二轮网页审查进一步要求：

- 检查第五臂没有再次给矛盾 C 的反向精确监督加权；实际实现以固定批分母分开 singleton/non-singleton，已满足。
- 三类条件概率下，非矛盾允许集合损失等于二元非矛盾监督。本实现使用全词表质量，实际分解为条件集合损失加合法答案质量惩罚；不能把收益全归因于新的集合推理。
- 分开报告整体方法与标准一致性的增量。两个任务共用 adapter，NLI 新损失带来的 MCQA 改变属于跨任务影响。
- FP32 仍有小量数值差异，保存每个视图类别 logits、top-2 margin，不删除近似平局样本。
- 所谓等计算对照严格含义是序列/有效 token 预算匹配，不是硬件 FLOPs 完全相同；保存实际 token、时间与显存。
- 未通过冻结门槛意味着本轮不能确认有效，不证明该类方法永远无效。

独立本地审查额外发现：源编号保留了生成时的标签顺序（NLI 编号段、MCQA 编号模 4）。
当前 trainer 从未将编号拼进 prompt，也不解析编号推导标签，编号只用于缓存/记录，未发现实际模型输入泄露。
但 public 文件元数据不是不可恢复标签的强盲化数据；这个限制必须披露。为保持冻结实验，本轮不重新编号；未来新数据应使用与标签独立的随机不透明 ID。
